## 1. Reward & Progression System
- **Star collection** — Earn 1-3 stars per game based on performance. Stars visible on main menu.
- **Trophy room** — Screen showing collected trophies/badges ("Speed Champion", "Color Master", "Shape Expert")
- **Unlockable content** — New car colors, coloring pages, or game themes that unlock after earning X stars
- **Daily streak** — "You played 3 days in a row!" celebration with a special sticker
- **Progress saved to localStorage** so Adam sees his achievements every time

## 3. Audio & Feedback Upgrades
- **Voice narration** — Use Web Speech API to read instructions aloud ("Tap 5 cars, Adam!")
- **Celebration animations** — Confetti/fireworks on achievements, not just text
- **Background music** — Gentle, toggleable background music per game
- **Encouraging phrases** — Rotate through different praise ("Amazing!", "You're so fast!", "Ka-chow!")

## 4. UX Improvements
- **Animated transitions** between games instead of instant switches
- **Parent settings panel** — Timer/session limits, difficulty adjustment, language preference saved
- **Fullscreen mode** — Better immersion on tablets
- **Idle animations** — Cars bouncing or driving on the menu screen to draw attention back
